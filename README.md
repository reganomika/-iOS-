# iOS Interview Prep — Q&A

## Структуры и классы

### Можно ли использовать в структуре инициализатор?

**Краткий ответ:**  
Да, в `struct` можно объявлять и использовать инициализаторы (`init`). Если вы не пишете свой `init`, Swift обычно генерирует для структуры *memberwise initializer* (инициализатор по хранимым свойствам) при определённых условиях.

**Развёрнутый ответ:**  
Инициализатор в структуре — нормальная и часто используемая вещь. Можно объявлять один или несколько `init`, делать перегрузки, использовать `init?`/`init!`, добавлять валидацию, вычислять значения свойств и т.д.

**Автоматические инициализаторы:**
- *Memberwise initializer* позволяет передать значения для хранимых свойств. Он **обычно генерируется**, если вы **не объявили кастомных инициализаторов** в основном объявлении структуры.
- `init()` появляется, если **все хранимые свойства имеют значения по умолчанию**.

Примеры:

```swift
struct User {
    let id: Int
    var name: String = "Anon"
}
// Memberwise: User(id:name:) доступен
// init() недоступен, потому что id без дефолта
